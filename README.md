# simpleMosNPN

Diseño de hardware con esquema eléctrico y placa de circuito impreso (PCB) en formato Autodesk EAGLE. Los archivos están guardados con la versión 9.6.2 de EAGLE.

El esquema incluye un módulo XIAO ESP32-S3, un MOSFET IRLZ44N, conectores, resistencias, un fusible y dos LED.

## Archivos

| Archivo | Descripción |
| --- | --- |
| [V1.sch](V1.sch) | Esquema eléctrico de la versión V1. |
| [V1.brd](V1.brd) | Diseño de la PCB de la versión V1. |
| [LICENSE](LICENSE) | Texto completo de la licencia. |

## Uso

1. Conserva `V1.sch` y `V1.brd` juntos en la misma carpeta.
2. Abre los archivos con una herramienta compatible con el formato EAGLE 9.6.2.
3. Para editar el diseño, mantén abiertos el esquema y la placa en EAGLE para conservar su sincronización.
